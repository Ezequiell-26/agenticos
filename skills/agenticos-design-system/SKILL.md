# AgentiCOS Design System Skill

Target a dark-first, keyboard-first AI/IDE workspace.

Rules:

- use semantic design tokens;
- keep one coherent density scale;
- use consistent typography and code typography;
- keep icons quiet and consistent;
- use restrained borders/radii;
- provide visible focus states;
- support reduced motion;
- avoid arbitrary per-component colors;
- avoid decorative gradients/glass effects as structure;
- compose from shared primitives instead of inventing one-off controls;
- every feature includes loading, empty, error and disabled states.

The intended direction is IDE-grade clarity with AgentiCOS-specific identity.
