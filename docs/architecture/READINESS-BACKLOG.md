Also undocumented: `AGENTICOS_ALLOW_REMOTE` and `AGENTICOS_CORS_ORIGINS` (the two switches without which the server refuses to bind off-loopback), `AGENTICOS_SECRET_KEY`, and `AGENTICOS_ALLOW_ANONYMOUS_PROVIDER` — the flag the desktop e2e test depends on (R8c), so a contributor cannot work out how that test passes from the config file alone. **Why it was not fixed on sight:** documenting 43 variables means deciding, per variable, whether it is operator-facing or internal, and `.env.example` is exactly the file where a wrong default or a secret-shaped line becomes a real hazard; that is a pass with the code as the source of truth for each entry, not an append. **Executable shape:** one line per variable with type, default and the `file:line` that reads it, plus an explicit note distinguishing `AGENTICOS_API_TOKEN` from `AGENTICOS_API_KEY`.
