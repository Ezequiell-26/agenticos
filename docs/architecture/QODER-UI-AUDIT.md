## Shared primitives found in Qoder

1. Motion: 160ms background/color transitions with `cubic-bezier(.2,.8,.2,1)`; 75ms snappy steps; springy `cubic-bezier(.34,1.56,.64,1)`; fade-in/out overlays; 2.8s rotating generating avatar; scrollbars nearly invisible until hover.
2. Icons: 1px strokes in the bundle; implemented at 1.5 for legibility at 13-14px.
3. Buttons: mint filled for primary with dark ink; raised neutral for secondary; plain text for link actions.
4. Empty states: dashed rounded tile, icon, bold title, muted one-line hint, optional mint CTA.
5. Filters: segmented chips inside a pill, grid/list toggles, sort dropdown aligned right.
6. Cards: flat `#0a0f0d` on `#0b110e`, 1px `#27332e`, 10px radius, no heavy shadows (shadows only on floating layers).
7. Type: Inter; body 13px; hero 20-22px semibold; labels 11-12px muted; monospace for file paths and counts.
